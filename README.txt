CAR GUIDE WEBSITE - UPDATE PACKAGE

Files in this ZIP:
- index.html: main vehicle search and model guide
- guides.html: practical car buying and maintenance articles (English and Arabic)
- about.html: About Car Guide (English and Arabic)
- contact.html: contact details (qeziouibdo@gmail.com)
- privacy-policy.html: privacy policy (English and Arabic)

HOW TO UPDATE GITHUB PAGES
1. Extract this ZIP on your computer.
2. Open your GitHub repository for Car Guide.
3. Choose Add file > Upload files.
4. Upload all five files into the repository's main/root folder (not inside a new folder).
5. Confirm that index.html replaces the old index.html, then commit the changes.
6. Wait for GitHub Pages to publish, then refresh https://uniexammaroc.github.io/car-guide/.
