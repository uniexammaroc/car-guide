AUTOATLAS — READY TO DEPLOY

This is a static website. To publish it free with Netlify: https://app.netlify.com/drop
1. Sign in or create a free Netlify account.
2. Upload the ZIP file (or drag the extracted AutoAtlas-site folder) to the Netlify Drop page.
3. Netlify will publish the site and give you a public URL.

Photos are loaded at runtime from Wikipedia/Wikimedia Commons. They are real reference photographs; availability and relevance depend on the external search results. Open each Commons image to review its author and licence.

The site uses NHTSA for vehicle make/model and recall data where available. NHTSA recall coverage is primarily for the US market.
